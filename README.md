# Сайт ГП «ПОЛЁТ» — демонстрационная версия

Статический прототип корпоративного сайта ООО НПП «ПОЛЁТ» (Обнинск).
Семь страниц, без серверной части: чистые HTML, CSS и немного JavaScript.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `about.html` | О компании |
| `catalog.html` | Продукция — шесть направлений |
| `production.html` | Производство — технологии и таблица выбора метода |
| `projects.html` | Проекты |
| `news.html` | Новости |
| `contacts.html` | Контакты |

## Особенности

- Внешних зависимостей нет: шрифт Lato подключён локально, Google Fonts не используется.
- Фотографии пережаты в WebP с запасным JPEG; герой весит 76 КБ вместо исходных 4 МБ.
- Схема проезда нарисована прямо на странице в SVG — карта не грузится наружу,
  Яндекс.Карты открываются только по клику.
- Вёрстка проверена на 1440, 1024 и 390 px: горизонтальной прокрутки нет.
- Анимации отключаются при системной настройке «уменьшить движение».

## Что ещё не сделано

- Форма заявки ничего не отправляет — это макет.
- Видео производства: съёмки пока нет, кнопка показывает подпись.
- Контактные данные взяты с действующего сайта и требуют подтверждения заказчиком.
